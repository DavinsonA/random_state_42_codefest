# A.R.P.I.A. Visual Foundation — Reference Notes

## Status

This document contains only the visual decisions that have been intentionally
adopted for A.R.P.I.A.

It is not a record of external visual references.

## Current visual direction

A.R.P.I.A. uses a dark aerospace/analytical visual language characterized by:

- very dark navy/black foundations
- blue and cyan as primary technical accents
- green for the F3 phenomenon and operational/success semantics
- amber for warning/evidence semantics
- red reserved for critical states
- cool, high-contrast text
- restrained visual effects
- professional technical composition
- controlled information density

## Design intent

The objective is to make A.R.P.I.A. feel like a serious analytical and
operational application with an aerospace identity.

The identity should not depend on decorative "sci-fi" styling.

## Deliberate exclusions

No external visual reference document is required to understand or implement
this visual foundation.

Agents and developers should use:

- `visual-system.md`
- `design-tokens.json`
- `AGENTS.md`

as the relevant project documentation.

## Scope boundary

This document does not define product functionality or UI components.
