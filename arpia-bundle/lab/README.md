# lab/

Experimentos desechables: prototipos de nodos, notebooks, pruebas de
prompts, scripts de un solo uso.

**Nada de aquí se despliega.** No es parte de `arpia/`, no lo referencia el
`Dockerfile`, y no debe importarse desde `arpia/src/`. Si algo de aquí
resulta útil, se promueve moviéndolo a `arpia/` — copiarlo, no enlazarlo.

Bórralo libremente entre iteraciones; no se versiona con la expectativa de
mantenerlo estable.
